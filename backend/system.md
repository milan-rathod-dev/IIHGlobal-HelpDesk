Design a backend for Help desk Lite - Support Ticket Tracker

Objective:

Develop a simple internal support-ticket application where users can :

1. Raise support tickets
2. Comment on their tickets
3. Work on their tickets
4. Work on tickets as a support agent (assign to self, change status)
5. Search for tickets

Roles and Screeens:

All roles use the same screens (Login/Signup, Dashboard, Ticket Details). The role only changes what each user sees and can do on them; no separate screen is needed per role. (Role-Based-Authentication)

Roles : 

1. Employee - See pnly their own tickets - No Status controls; sees the view-only messages
2. Agent - Sees all tickets - "Assign to me" button and status drop-down
3. Admin - Sees all tickets - "Assign to me" button and status drop-down
